## 收录标准

问题满足以下任意条件时，应写入本目录：

1. 同类问题已经出现过多次。
2. 第一次解决时经历了多轮尝试或错误方向。
3. 问题与架构边界、构建链路、权限链路、动态路由或软删除唯一约束有关。
4. 问题容易被后续开发者按直觉修错。

## 编写格式

每个问题尽量说明：

1. 现象。
2. 根因。
3. 正确处理方式。
4. 不建议的处理方式。
5. 相关文件或模块。
