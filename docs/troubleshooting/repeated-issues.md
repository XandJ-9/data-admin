# 反复问题处理手册

## 1. 业务任务定义与 datatask 边界混淆

现象：

- 新增业务任务时，容易把完整业务配置直接塞进 `datatask.Task`。
- 手动执行后，任务被意外发布到任务中心并开始参与调度。
- 业务模块和任务中心出现双写真源。

根因：

- 没有区分业务任务定义、平台任务镜像和执行实例。

正确处理：

1. `datasource`、`dataintegration`、`datadev` 保存业务定义。
2. `datatask.Task` 只保存平台镜像、调度索引和发布快照。
3. `datatask.TaskInstance` 记录每次执行。
4. 手动执行可以创建实例，但不等于自动发布调度任务。

不建议：

- 为了让调度器方便读取，把来源模块的完整业务字段复制到 `Task`。
- 为了减少表数量，恢复业务模块私有执行历史表。

相关模块：

- `apps.datatask`
- `apps.datasource.task_handler`
- `apps.dataintegration.task_source`
- `apps.datadev.task_source`

## 2. SourceHandler 返回结构不稳定

现象：

- 来源模块抛异常导致任务中心接口 500。
- 不同来源模块返回结构不同，前端执行记录无法统一展示。
- 任务详情页错误信息缺失或 result_summary 结构混乱。

根因：

- 来源执行没有统一 envelope。

正确处理：

1. 来源模块执行返回 `{ok,msg,data}`。
2. `TaskService.execute_task` 负责兜底异常和结构归一化。
3. 失败时写入 `TaskInstance.error_message`，成功或失败摘要写入 `result_summary`。

不建议：

- 在各来源 View 中直接操作实例状态。
- 让异常冒泡到任务中心 API。

## 3. 前端菜单、动态路由和页面路径不一致

现象：

- 菜单点击后 404。
- 返回列表依赖路由名时失败。
- 页面文件还在，但菜单种子不再指向它。

根因：

- 前端静态页面、系统菜单种子和后端权限码没有一起维护。

正确处理：

1. 以 `system` 菜单种子里的 `component` 路径为准。
2. 新增页面时同步更新菜单、权限码和前端 API。
3. 历史断链页面和 API 封装应清理，不长期保留。
4. 返回列表优先使用稳定路径，不依赖可能不存在的动态路由名。

不建议：

- 只新增前端路由，不同步系统菜单。
- 保留未接入后端的入口，等待以后再说。

## 4. 软删除唯一约束与 create-upsert 混用

现象：

- 新增接口、报表或业务编码时，意外复用旧记录。
- 编辑后删除触发唯一约束冲突。
- 前端收到数据库约束错误，而不是明确的重复编码提示。

根因：

- 通用 create 流程曾经按唯一字段静默复用旧记录，和软删除唯一约束叠加后语义不清。

正确处理：

1. `BaseViewSet.perform_create` 默认禁止静默复用旧记录。
2. 确需 create-upsert 的子类必须显式开启。
3. 业务编码重复应在业务层显式校验并返回明确提示。
4. 更新或删除关联关系前，先清理历史软删除重复记录。

不建议：

- 把重复编码交给数据库唯一约束兜底。
- 在通用基类里恢复默认 create-upsert。

## 5. 数据服务接口路径和只读 SQL 治理

现象：

- 前端调用不存在的导出路径。
- 查询或接口执行允许危险 SQL。
- 导出数据量失控。

根因：

- 前后端 API 路径没有以当前路由为准；SQL 治理散落在调用点。

正确处理：

1. 数据服务统一使用 `/dataservice/` 后端前缀。
2. 接口执行导出使用当前存在的 export 路径。
3. 只允许单条 SELECT / WITH / SHOW / DESCRIBE / EXPLAIN。
4. 普通查询和导出都设置最大行数限制。

不建议：

- 为兼容历史前端调用恢复不存在的 `/export-data` 路径。
- 在前端只做 SQL 类型判断。

## 6. xterm 生产构建压缩问题

现象：

- 开发模式正常，生产构建后浏览器终端运行 `vim` 等全屏程序崩溃。
- 控制台出现 `requestMode` 相关 `ReferenceError`。

正确处理：

- 按 [xterm 生产构建压缩问题](esbuild-xterm-requestMode-bug.md) 中的方案处理。

不建议：

- 只通过 manualChunks 隔离 xterm。
- 回退到逐命令 subprocess 终端架构。
