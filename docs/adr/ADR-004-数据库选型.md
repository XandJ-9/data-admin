# ADR-004: 数据库选型

**Status**: Accepted  
**Date**: 2026-03-31

## Context

项目作为数据管理平台，自身需要一个元数据存储库，同时需要能够连接和查询多种外部数据源。

## Decision

### 系统元数据库（平台自身）
- **开发/测试环境**: SQLite
  - 零配置，无需安装数据库服务
  - 适合本地开发和 CI/CD 流水线
- **生产环境**: 支持切换到 MySQL / PostgreSQL（Django ORM 跨库兼容）

### 外部数据源（被管理的目标库）
通过 `apps/dbutils/` 模块支持多种数据源类型：

| 类型 | 驱动 |
|------|------|
| MySQL / MariaDB | `pymysql` |
| PostgreSQL | `psycopg2` |
| SQLite | 内置 |
| StarRocks | MySQL 协议兼容 |
| Presto / Trino | `pyhive` |

统一通过 `get_executor(info)` 工厂函数获取对应执行器，执行器只允许 SELECT/WITH/SHOW/DESCRIBE/EXPLAIN 语句（SQL 安全限制）。

## Consequences

**优点**:
- 开发环境零配置，CI 无需启动数据库服务
- 外部数据源高扩展性，新增类型只需实现 `DataSourceExecutor` 接口

**缺点/风险**:
- SQLite 不支持并发写入，生产环境必须切换到 MySQL/PostgreSQL
- 不同数据库方言差异（如 JSON 操作、窗口函数）需要在 executor 层处理
