# ADR-001: 技术栈选型

**Status**: Accepted  
**Date**: 2026-03-31

## Context

项目需要一套统一的数据管理平台，涵盖数据源管理、元数据目录、在线SQL查询、数据接口服务、ETL编排和系统管理等功能。需要选定后端框架、前端框架及配套生态。

## Decision

- **后端**: Django 5.2 + Django REST Framework 3.16 + SimpleJWT  
  - Django 生态成熟，DRF 提供完整的 REST API 脚手架  
  - SimpleJWT 轻量，满足无状态认证需求  
  - drf-spectacular 自动生成 OpenAPI 文档  
- **前端**: Vue 3.5 + Element Plus 2.10 + Vite 6 + Pinia  
  - Vue 3 Composition API 利于逻辑复用  
  - Element Plus 提供完整企业级 UI 组件库  
  - Vite 构建速度快，开发体验好  
  - 使用javascript 语言
- **开发数据库**: SQLite（零配置，适合本地开发）  
- **外接数据库**: 支持 MySQL / PostgreSQL / Presto / StarRocks / SQLite

## Consequences

**优点**:
- 技术栈统一，学习成本低
- DRF + Vue3 生态丰富，组件/插件齐全
- SQLite 零依赖，CI/测试无需额外服务

**缺点/风险**:
- 前端当前未使用 TypeScript，存在类型安全隐患（见 TD-001）
- Django 同步模型在高并发 ETL 调度下存在瓶颈，需引入异步任务队列（Celery/等）
