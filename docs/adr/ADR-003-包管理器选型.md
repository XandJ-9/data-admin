# ADR-003: 包管理器选型

**Status**: Accepted  
**Date**: 2026-03-31

## Context

项目需要管理 Python 后端和 Node.js 前端的依赖。传统的 `pip` 和 `npm` 存在速度慢、版本锁定不可靠等问题，需要选择更可靠的包管理方案。

## Decision

- **后端（Python）**: 使用 `uv`
  - 依赖解析和安装速度极快（基于 Rust 实现，比 pip 快 10-100x）
  - 原生支持 lock file 和 venv 管理
  - 与 `pip` 接口兼容，迁移成本低
  - 命令：`uv pip install`，`uv run manage.py`

- **前端（Node.js）**: 使用 `pnpm`
  - 使用硬链接共享全局 store，节省磁盘空间
  - 安装速度快于 npm/yarn
  - 严格的依赖隔离（防止幽灵依赖）
  - 命令：`pnpm install`，`pnpm dev`，`pnpm build:prod`

## Consequences

**优点**:
- 本地开发环境搭建速度大幅提升
- lock file 保证依赖版本一致性

**缺点/风险**:
- 部分 CI 环境默认只安装 pip/npm，需要额外安装 uv/pnpm
- 团队成员需要学习新工具命令
