# 数据集成模块详细设计与实现文档

## 1. 模块概述
数据集成模块主要用于配置和管理异构数据源之间的数据同步任务。它允许用户定义数据的来源、去向、字段映射关系以及同步策略（全量/增量、定时/手动），是数据平台中数据流转的核心配置中心。

> **注意**：当前代码库主要实现了任务的**配置管理（Control Plane）**功能，暂未发现具体的**任务执行引擎（Execution Plane）**代码（如具体的 ETL 逻辑或调度执行器），推测执行端可能作为独立服务存在。

## 2. 系统架构

### 2.1 技术栈
- **前端**：Vue 3 + Element Plus
- **后端**：Python Django REST Framework (DRF)
- **数据存储**：MySQL (Django ORM)

## 3. 功能特性

### 3.1 任务类型支持
支持以下三种流向的数据同步：
1. **数据库 → 数据库** (`dbToDb`)
2. **数据库 → Hive** (`dbToHive`)
3. **Hive → 数据库** (`hiveToDb`)

### 3.2 核心配置能力
- **多级元数据选择**：支持 `数据源 -> 数据库 -> 数据表` 的级联选择。
- **字段映射**：支持源字段到目标字段的一一映射配置。
- **同步策略**：
    - **Where 条件**：支持自定义 SQL 过滤条件（如 `status = 1`）。
    - **同步方式**：
        - **全量同步** (`full`)
        - **增量同步** (`incremental`)：支持基于自增 ID、时间戳或自定义字段进行增量抽取。
- **调度配置**：
    - **手动执行** (`manual`)
    - **定时执行** (`cron`)：支持 Cron 表达式配置，并提供分组调度功能。

## 4. 数据模型设计

后端核心模型为 `IntegrationTask`，存储在表 `dataintegration_task` 中。

| 字段名 | 类型 | 说明 | 关键细节 |
| :--- | :--- | :--- | :--- |
| `name` | Char | 任务名称 | 索引字段 |
| `type` | Char | 任务类型 | 选项：`dbToDb`, `dbToHive`, `hiveToDb` |
| `schedule` | JSON | 调度配置 | 结构：`{ "type": "cron/manual", "cronExpr": "* * *...", "group": "default" }` |
| `detail` | JSON | 任务详情 | 包含源/目标配置、字段映射、同步条件等核心逻辑 |
| `status` | Char | 状态 | `0`: 正常, `1`: 停用 |
| `remark` | Char | 备注 | |

## 5. 详细配置结构 (JSON Schema)

`detail` 字段是任务配置的核心，其内部结构如下：

```json
{
  "source": {
    "dataSourceId": 1,
    "database": { "name": "db_name", ... },
    "table": { "name": "table_name", ... }
  },
  "target": {
    "dataSourceId": 2,
    "database": { "name": "target_db", ... },
    "table": { "name": "target_table", ... }
  },
  "sourceColumns": ["id", "name", "age"],
  "targetColumns": ["u_id", "u_name", "u_age"],
  "fieldMappings": [
    { "source": "id", "target": "u_id" },
    { "source": "name", "target": "u_name" }
  ],
  "syncConfig": {
    "where": "create_time > '2023-01-01'",
    "mode": {
      "type": "incremental",  // 或 "full"
      "incrementField": "id",
      "incrementType": "id"   // 选项: "id", "timestamp", "custom"
    }
  }
}
```

## 6. API 接口说明

基础路径：`/data-api/dataintegration/task`

| 方法 | 路径 | 功能 | 关键参数 |
| :--- | :--- | :--- | :--- |
| `GET` | `/` | 获取任务列表 | 支持 `taskName`, `taskType`, `status` 过滤 |
| `POST` | `/` | 创建任务 | `taskName`, `taskType`, `schedule`, `detail` |
| `GET` | `/{id}` | 获取任务详情 | |
| `PUT` | `/{id}` | 更新任务 | 完整更新任务信息 |
| `DELETE` | `/{id}` | 删除任务 | 逻辑删除 (`del_flag='1'`) |

**权限控制**：所有接口均需要认证 (`IsAuthenticated`) 且受角色权限控制 (`HasRolePermission`)。

## 7. 前端交互逻辑

1. **元数据加载 (`DbSourceSelector.vue`)**：
   - 监听 `dataSourceId` 变化，调用 `/api/datasource/databases` 加载数据库列表。
   - 监听 `database` 变化，调用 `/api/datasource/tables` 加载表列表。
   - 监听 `table` 变化，调用 `/api/datasource/columns` 自动获取字段列表。

2. **数据回显与默认值 (`SyncConfigDetail.vue`)**：
   - 使用 `useVModel` 实现双向绑定。
   - 深度监听 `detail` 对象，确保 `source`, `target`, `syncConfig` 等子对象结构存在，防止空指针异常。

3. **任务保存 (`taskDetail.vue`)**：
   - 根据路由参数 `id` 判断是新增 (`addTask`) 还是更新 (`updateTask`)。
   - 保存成功后会清理 `TagsView` 缓存并返回列表页。
