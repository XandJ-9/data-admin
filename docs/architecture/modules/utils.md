# utils 模块架构

## 模块定位

`apps.utils` 提供项目级工具函数，目前主要承接 Excel 相关导入导出辅助能力。

它是轻量工具模块，不承载业务流程和跨模块领域规则。

## 核心职责

1. 提供 Excel 读写、导入导出相关工具。
2. 为业务模块提供可复用的文件处理辅助。
3. 保持工具函数无业务状态、低耦合。

## 关键文件

- `excel.py`

## 边界约束

1. 不把业务校验、权限判断或任务执行逻辑放入 `utils`。
2. 工具函数应保持输入输出清晰，避免依赖全局请求上下文。
3. 如果工具能力开始承载复杂领域规则，应迁回对应业务模块或公共服务。

## 演进方向

1. 把通用文件处理能力整理为稳定 API。
2. 为导入导出场景补齐格式校验、错误摘要和测试覆盖。
