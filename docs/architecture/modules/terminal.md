# terminal 模块架构

## 模块定位

`apps.terminal` 提供浏览器中的交互式终端能力，用于研发辅助和运维操作。

当前架构采用 PTY 交互式会话，而不是逐命令 `subprocess.run`。

## 核心职责

1. 维护 `TerminalSession`，记录用户终端会话。
2. 维护 `TerminalCommand`，记录命令历史和输出摘要。
3. 通过 WebSocket / Channels 连接前端 xterm 组件。
4. 通过 PTY 保留 shell 进程状态，支持 `vim`、`top` 等交互式程序。
5. 做基础权限、安全和命令审计。

## 边界约束

1. 不回退到前端拼完整命令、后端逐条 subprocess 执行的模式。
2. 前端生产构建中 xterm 相关压缩问题按 troubleshooting 手册处理。
3. 终端能力只作为辅助入口，不承担任务调度和数据开发执行器职责。
4. 后续增加远程主机能力时必须补齐授权、审计和隔离策略。

## 演进方向

1. 完善 session 生命周期、断线重连和命令审计。
2. 增强危险命令控制和可配置白名单。
3. 将终端权限与系统角色权限打通。
