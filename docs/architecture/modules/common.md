# common 模块架构

## 模块定位

`apps.common` 提供后端公共能力，包括加密、异常、分页、通用 mixin 和模型辅助函数。

它是跨模块基础设施，不承载业务状态，也不保存业务数据。

## 核心职责

1. 提供密码等敏感字段加密能力。
2. 提供统一异常类型和异常处理辅助。
3. 提供通用分页能力。
4. 提供 ViewSet mixin 和模型工具函数。
5. 为业务模块减少重复的基础代码。

## 关键文件

- `encrypt.py`
- `exceptions.py`
- `mixins.py`
- `pagination.py`
- `util_model.py`

## 边界约束

1. 公共模块只放跨模块通用能力，不放某个业务模块的特殊规则。
2. 不在 `common` 中反向 import 业务模块模型。
3. 通用 mixin 的默认行为必须保守，避免影响所有业务 ViewSet。
4. 涉及 create、update、delete 等通用行为变更时，需要评估软删除、唯一约束和权限影响。

## 演进方向

1. 将稳定的错误响应、分页和审计行为继续沉淀为公共能力。
2. 对影响面大的基类行为保持显式开关，避免隐式改变业务语义。
