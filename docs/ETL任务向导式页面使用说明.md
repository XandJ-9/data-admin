# ETL任务向导式页面使用说明

## 概述

本文档说明了ETL任务创建/编辑页面的使用方法。该页面采用**向导式交互**设计，将复杂的ETL任务配置分解为5个简单步骤，引导用户快速完成任务配置。

## 功能特性

### 1. 向导式流程
- **5步配置流程**：基本信息 → 源端配置 → 转换映射 → 目标端配置 → 高级配置
- **步骤导航**：左侧进度条显示当前步骤，可点击已完成的步骤跳转
- **完成度指示**：实时显示配置完成百分比
- **数据验证**：每一步都有完整的表单验证，确保配置正确

### 2. 智能辅助
- **自动填充**：根据前面步骤的配置，自动填充后续步骤的相关字段
- **智能映射**：一键自动匹配源表和目标表的字段
- **配置预览**：随时查看完整配置的JSON格式
- **草稿保存**：支持保存草稿，随时继续编辑

### 3. 丰富的配置选项
- **多种任务类型**：支持数据集成、SQL任务
- **灵活的抽取方式**：全量、增量（支持时间戳和自增ID）
- **多种写入模式**：追加、覆盖、Upsert
- **完整的调度配置**：手动执行、定时调度（Cron表达式）
- **资源控制**：CPU、内存、并发数配置
- **失败重试**：可配置重试次数和间隔
- **任务依赖**：支持配置前置任务依赖
- **告警通知**：支持邮件、短信、Webhook通知

## 使用步骤

### 步骤1：基本信息

1. **任务名称**：输入有意义的任务名称，如 `sync_user_to_dw`
2. **任务编码**：唯一标识，自动生成，可手动修改
3. **ETL类型**：选择任务类型
   - **数据集成**：用于数据源之间的同步
   - **SQL任务**：使用Spark SQL进行数据转换
4. **业务域**：选择任务所属业务域（可自定义）
5. **优先级**：选择任务执行优先级（低/中/高）
6. **状态**：选择创建后是否立即启用

> **提示**：系统会根据ETL类型自动选择最合适的执行器（DataX或Spark SQL）

### 步骤2：源端配置

#### 数据源选择
1. 选择已配置的源数据源
2. 选择数据库（会自动加载数据库列表）
3. 选择查询类型：
   - **表查询**：直接选择整张表
   - **SQL查询**：自定义SQL查询

#### 表查询模式
- 选择源表名称
- 选择抽取模式：
  - **全量抽取**：每次抽取全部数据
  - **增量抽取**：只抽取新增或变更的数据
- 如果选择增量抽取，需配置：
  - **增量字段**：选择用于判断增量的字段（如 updated_at）
  - **增量策略**：时间戳 或 自增ID

#### SQL查询模式
- 输入SQL查询语句
- 支持使用变量：
  - `${last_run_time}`：上次运行时间
  - `${biz_date}`：业务日期
- 点击"格式化"美化SQL
- 点击"预览结果"查看数据样例

### 步骤3：转换映射

#### 数据集成类型
1. **字段映射配置**
   - 查看源字段和目标字段列表
   - 点击"智能映射"自动匹配字段
   - 手动调整映射关系
   - 为字段添加转换规则（可选）

2. **转换规则示例**
   - `UPPER(column_name)`：转大写
   - `CAST(column AS INT)`：类型转换
   - `DATE_FORMAT(column, 'yyyy-MM-dd')`：日期格式化
   - `NVL(column, '')`：空值处理

3. **数据过滤**（可选）
   - 输入WHERE条件，如 `status = 1 AND amount > 0`

#### SQL任务类型
1. **SQL脚本编辑**
   - 在编辑器中编写Spark SQL
   - 支持语法高亮和自动补全
   - 使用模板快速开始

2. **可用变量**
   - `${biz_date}`：业务日期，格式 YYYY-MM-DD
   - `${biz_date_prev}`：前一天业务日期
   - `${last_run_time}`：上次运行时间
   - `${current_time}`：当前时间

3. **输出字段配置**
   - 定义输出字段的名称和类型
   - 点击"从SQL解析字段"自动提取

### 步骤4：目标端配置

#### 基本配置
1. **目标数据源**：选择数据写入的目标数据源
2. **目标数据库**：选择目标数据库
3. **目标表名称**：
   - 从列表选择现有表
   - 或输入新表名（会自动创建）

#### 写入模式
- **追加（Append）**：将数据追加到目标表，保留原有数据
- **覆盖（Overwrite）**：清空目标表后写入新数据（⚠️ 会删除原有数据）
- **更新（Upsert）**：根据主键判断，存在则更新，不存在则插入

  > 如果选择Upsert模式，需要指定主键字段（支持多字段组合主键）

#### 分区配置（可选）
- 选择分区字段（如 dt、biz_date）
- 设置分区值（如 `${biz_date}`）
- 选择分区策略：
  - **静态分区**：每次写入固定分区值
  - **动态分区**：根据数据自动分区

#### 钩子脚本（可选）
- **前置SQL**：写入数据前执行的SQL（如清理历史数据）
- **后置SQL**：写入数据后执行的SQL（如刷新统计信息）

### 步骤5：高级配置

#### 调度配置
- **执行方式**：
  - **手动执行**：保存后需要手动触发
  - **定时调度**：按照Cron表达式自动执行

- **Cron表达式配置**：
  - 使用可视化界面配置
  - 支持简单配置（每天、每周、每月）
  - 支持直接输入Cron表达式
  - 显示下次执行时间

#### 资源配置
- **执行器内存**：2GB / 4GB / 8GB / 16GB
- **CPU核心数**：1-8核
- **执行器实例数**：1-10个

> 系统会根据配置计算总资源使用量

#### 失败重试
- **重试次数**：任务失败后的最大重试次数（0-5次）
- **重试间隔**：每次重试之间的等待时间（30-600秒）
- **超时时间**：任务执行超时时间，超时后将自动取消（60-7200秒）

#### 任务依赖（可选）
- 搜索并添加依赖任务
- 选择依赖策略：
  - **全部成功**：所有依赖任务都成功后才执行
  - **任一成功**：任一依赖任务成功即执行
  - **全部完成**：不管成功失败，完成就执行
- 设置等待超时时间

#### 告警通知（可选）
- 选择告警方式：邮件 / 短信 / Webhook
- 选择告警时机：任务失败 / 成功 / 超时 / 重试失败
- 添加通知对象

## 配置保存

### 保存草稿
- 点击顶部"保存草稿"按钮
- 可以随时保存当前配置，稍后继续编辑
- 保存后任务状态为"草稿"

### 创建/发布任务
- 完成所有步骤后，点击"创建任务"按钮
- 系统会验证所有配置
- 验证通过后，可以选择是否立即执行任务

## 配置预览

- 点击顶部"预览配置"按钮
- 查看完整配置的JSON格式
- 可以复制配置用于备份或迁移

## 常见场景

### 场景1：MySQL到Hive的全量同步
1. 基本信息：选择"数据集成"类型
2. 源端：选择MySQL数据源，选择表，全量抽取
3. 映射：智能映射字段
4. 目标：选择Hive数据源，输入目标表名，追加模式
5. 高级：配置定时调度（每天凌晨2点）

### 场景2：MySQL增量同步到数仓
1. 基本信息：选择"数据集成"类型
2. 源端：选择MySQL数据源，选择表，增量抽取，选择 `updated_at` 字段
3. 映射：智能映射字段，添加转换规则
4. 目标：选择Hive数据源，输入目标表名，Upsert模式，选择主键
5. 高级：配置定时调度（每小时执行一次）

### 场景3：SQL统计分析
1. 基本信息：选择"SQL任务"类型
2. 源端：跳过（SQL任务不需要配置源端）
3. 映射：编写Spark SQL，使用模板
4. 目标：选择Hive数据源，输入结果表名，覆盖模式
5. 高级：配置定时调度（每天凌晨3点）

## 注意事项

1. **首次使用**：建议先使用"智能映射"功能，了解字段映射规则
2. **增量同步**：确保源表有合适的增量字段（时间戳或自增ID）
3. **Upsert模式**：必须选择正确的主键字段，否则可能导致数据重复
4. **资源配置**：根据数据量合理设置资源，避免资源浪费或不足
5. **任务依赖**：合理配置依赖关系，确保数据流转顺序正确
6. **测试验证**：建议先在测试环境验证任务配置，再部署到生产环境

## 错误处理

如果遇到错误：

1. **验证失败**：查看错误提示，修改对应配置
2. **连接失败**：检查数据源配置是否正确
3. **执行失败**：查看执行日志，定位问题原因
4. **性能问题**：调整资源配置或优化SQL脚本
